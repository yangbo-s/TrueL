# 快速处理与左右对照

GOAL-070：选中文字后快速阅读、调整并替换；手动输入时并排比较原文与结果。

| 需求 / 验收 | 行为与证据计划 |
| --- | --- |
| REQ-070 / AC-070 | 快速翻译、快速改写默认 Ctrl+C+C、Ctrl+A+A，只显示结果岛；加载、空选区、失败均在同一窗口内反馈。 |
| REQ-071 / AC-071 | 结果就绪时 Return 替换可编辑原选区；调整框获得焦点时 Return 只提交调整。绿色按钮与当前动作一致。IME 确认和 Shift+Return 不触发替换。 |
| REQ-072 / AC-072 | 打开翻译/改写显示左右等宽岛屿；标题、正文、滚动条、底栏对齐；正文 14 pt / 22 pt，12 pt 内外边距、8 pt 岛间距。 |
| REQ-073 / AC-073 | 连续快捷键保留原选区；未完成序列归还原按键。保留自定义和已关闭的快捷键，只迁移旧默认值。 |
| REQ-074 / AC-074 | 替换核对来源进程、控件、选区范围和文本；只读、已改变或已关闭来源不写入。复制仍可用。 |
| REQ-075 / AC-075 | 单窗口切换、大小记忆；浅深色截图、键盘流程、真实选择/替换验证；更新使用文档与安装包。 |

IN-070：当前前台应用的 UTF-8 选中文字、配置的快捷键序列（1 秒内）、后续调整指令。空选区为可恢复错误；无权限提示设置入口；不会自动提交剪贴板旧内容。
OUT-070：现有 AI 管线产生的翻译/改写结果；替换仅由明确 Return 或按钮触发。失败保留结果，重复提交沿用现有取消/请求代际保护。
CON-070：SwiftUI/AppKit、同一 NSPanel、现有签名及凭据代理不变。保留 Control 和 Command 的区别。无新服务或依赖。
OOS-070：不更换视觉风格、模型服务、凭据存储；不模拟在只读网页中粘贴。
ASM-070：普通窗口始终保留左右两栏（无结果时右侧为空状态）；快速完成一次调整后回到结果，Return 再次表示替换。

ADR-070：复用现有结果和编辑组件，以一个窗口会话状态区分快速/对照布局；不另建快速窗口（避免生命周期、焦点和样式分叉）。Return 通过同一动作策略驱动窗口事件和按钮样式。非复制序列需暂存配置前缀事件，否则 Ctrl+A 的原生行首动作会先破坏选区；Command+C 序列保留原生复制。

MOD-070：PopupSession 管理布局、焦点和 Return 意图；PopupView 渲染等高岛屿；AppDelegate 保管单窗口和来源绑定；ShortcutMonitor 仅暂存已配置前缀并在失败时归还；SelectionBridge 保留严格 AX 写入校验。
IF-070：beginInput(text, mode, presentation, canReplaceSelection) 原子取消旧请求、绑定来源、切换布局并提交。快捷键持久化兼容 v2，迁移标记防止重复覆盖。事件回放标识只用于本进程过滤，无键盘日志。
