# 0.4.1 顶栏与操作图标验收

GOAL-076：将任务切换放到顶栏，稳定显示所有提交类按钮的回车图标。

| 需求 / 验收 | 实现与检查 |
| --- | --- |
| REQ-076 / AC-076 | 翻译、改写紧邻红绿灯右侧，共用顶栏中心线；TrueL 标题保持窗口居中；原文岛标题为「原有内容」，与右侧标题及正文起点对齐。 |
| REQ-077 / AC-077 | 提交、替换、调整和重试统一使用同尺寸的系统回车图标；失去主动作焦点后仍显示，仅绿色跟随当前 Return 意图。 |
| REQ-078 / AC-078 | 保留快速 / 左右对照两种布局、单窗口、原生输入法及回车路由；快速模式切换任务后处理同一原文，只有仍有效的选区绑定能延续。 |

IN-076：已有原文、结果、任务和输入焦点。OUT-076：重排后的顶栏与常显回车符号，不增加窗口或更改全局快捷键。CON-076：保留 52 pt 顶栏、28 pt 控件、12 pt 内边距和现有字体、圆角、毛玻璃。OOS-076：不改 API、凭据、权限和结果布局。

ADR-076 / MOD-076：任务切换复用现有按钮，在 WindowChrome 的左侧预留区域内叠放；不复制整个标题栏或增加新工具条。AppDelegate 负责快速模式的任务切换与来源绑定，PopupView 只展示按钮。所有提交图标复用 ReturnGlyph；PopupSession 继续决定绿色主动作和实际回车路由。

| 测试 | 关联 | 预期 |
| --- | --- | --- |
| TC-076 | 076、077 | 快速 / 对照、浅深色、宽窄、结果 / 调整焦点截图：标题栏不重叠；所有回车图标可见，原文标题与正文对齐。 |
| TC-077 | 078 | 快速切换自动处理同一原文，保留有效绑定；只读、失效绑定不恢复。普通模式保持手动提交。原生回车和空调整框测试继续通过。 |
| TC-078 | 076—078 | 完整测试、设置页截图、固定组件及打包检查、签名更新与公开下载验证。 |

实施顺序：重排与图标 → 任务切换回归 → 实际截图核对 → 构建、文档和发布。

## 界面与交互证据

- TC-076 通过：28 张快速 / 对照 / 调整焦点 / 加载 / 只读 / 错误截图，加上 62 张主窗与五个设置页状态截图，均已逐组审阅。浅深色、默认与缩放尺寸下，顶栏没有重叠，TrueL 保持居中，「原有内容」与结果标题和正文起点对齐。所有提交类动作都显示同一回车符号，失焦时不隐藏。
- TC-077 通过：143 项 Swift 测试 / 16 个 suite 通过。新增任务切换用例覆盖有效、只读、已失效选区和空原文，普通模式仍等待手动提交。原生调整框回车、空调整不误替换、单窗口和布局回归继续通过。对独立预览窗口发送真实鼠标事件，两个顶栏任务按钮均切换成功；标题区仍能拖动，实测位移为 24 × 16 pt。
- TC-078 的本地代码检查通过：4 项凭据打包测试、3 项发布测试、网格和差异检查通过。Impeccable 检测无发现；原生 UI 的结论以实际截图和交互为依据。

本轮新增测试首先发现切换任务后遗留旧调整指令，已在切换时清空并通过回归。额外鼠标探针曾超时：调用栈确认是脚本的无参数 `pause()` 解析成 Darwin 系统阻塞函数；将辅助函数更名后完成真实点击与拖动验证。未为此更改应用的事件处理或系统权限。

证据位于本地 `artifacts/header-0.4.1/`：`workflows` 为 28 张工作流截图，`all` 为 62 张完整矩阵，`review` 为检视拼图；`clicked-rewrite.png`、`clicked-translation.png`、`dragged-window.png` 为真实鼠标操作后截图。最终测试日志为 `logs/tests.log`、`logs/native-header.log`。README 与使用指南中的图片同步为本版真实窗口截图。

界面使用模拟数据，生产 API 管线保持不变。测试环境为 macOS 27.2.1、2× 屏幕；未另测 macOS 26、1× 屏幕，也未执行完整 VoiceOver / Accessibility Inspector 审计。未退出或替换用户日常使用的应用，独立预览进程已关闭。
