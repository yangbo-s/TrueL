# 界面用语

| 用语 | 含义 |
| --- | --- |
| 快速翻译 / 快速改写 | 对外部选中文字直接处理，只显示结果 |
| 打开翻译 / 打开改写 | 进入可编辑的左右对照工作窗 |
| 原有内容 | 左右对照工作窗中可编辑的原文 |
| 翻译 / 改写 | 当前工作任务 |
| 译文 / 修改结果 | 模型处理后的正文 |
| 替换 | 快速模式写回原选区；对照模式放回左侧原文 |
| 复制结果 | 将完整结果放到剪贴板 |
| 用法提示 | 改写结果的语言用法说明 |
| 检测语言 | 本地识别原文语言；也可手动选择 |
| 目标语言 | 翻译结果使用的语言 |
| 互换语言 | 以译文为新原文，反向翻译 |
| 翻译风格 / 改写风格 | 各自保存的表达预设，每次从原文生成 |
