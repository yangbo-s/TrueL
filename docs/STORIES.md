# 工作流验收故事

## STORY-070：选中后快速处理

阅读或写作时，选中文字即可获得翻译或改写，并在可编辑来源中替换。

验收：REQ-070、071、073、074；快捷键不改变选区，结果单岛显示，回车和绿色按钮对应；关闭或点击外部后重开回到双栏。

UX:
- Flow：选中文字 → Ctrl+C+C / Ctrl+A+A → 结果 → Return 替换；风格选择 → 从原文重新生成。
- Surface：现有浮窗内的一张结果岛；加载、错误与结果同位置。
- States：空选区显示重选提示；请求失败可重试；只读结果可复制，替换禁用；失效选区显示错误。
- Words：快速翻译、快速改写、译文、修改结果、替换、翻译风格、改写风格。
- Access：Return 动作随普通/快速入口改变，IME 使用原生处理，按钮有文字或标签及悬停提示。

## STORY-072：左右对照编辑

手动输入和处理文字时，原文和结果同时可见，便于比较。

验收：REQ-072、075；两侧等宽等高、标题/正文/底栏对齐，共用 14 pt 字体与 22 pt 行高；快速入口不另开窗口。

UX:
- Flow：打开翻译 / 打开改写 → 左侧输入 → Return 提交 → 右侧阅读 → 复制或替换。
- Surface：同一浮窗的左右两张岛，各自滚动。
- States：右侧空状态、处理中、结果、错误；保留复制、修改解释与预设风格。
- Words：翻译、改写、译文、修改结果、复制结果、替换。
- Access：Shift+Return 换行；原生红绿灯、键盘焦点及输入法；两侧语言、底栏和快速模式复用组件。

## STORY-079：语言方向与表达风格

验收：REQ-079–086；自动语言、目标语言清楚分列；操作行对称；快捷会话不延续到正常打开。

UX:
- Flow：普通打开 → 原文检测/手选语言 → 选择目标 → Return → 结果 → 风格重新生成 / 复制 / 替换；互换 → 译文成为原文并反向翻译。
- Surface：原有单窗口；语言位于各栏标题行右侧，模型与风格位于底部左侧；复制紧邻风格，替换右下对齐提交。
- States：未知语言显示检测语言；无结果时互换/复制/替换禁用；加载可停止；只读快捷结果可复制；失败原位重试。
- Words：原有内容、译文、修改结果、检测语言、目标语言、互换语言、翻译风格、改写风格。
- Access：所有下拉保留原生菜单键盘导航，符号按钮提供标签与悬停帮助；普通 Return 提交、快速 Return 替换。关闭/失焦结束快速会话，重开保留原文和完整结果。
