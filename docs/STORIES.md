# 工作流验收故事

## STORY-070：选中后快速处理

阅读或写作时，选中文字即可获得翻译或改写，并在可编辑来源中替换。

验收：REQ-070、071、073、074；快捷键不改变选区，结果单岛显示，回车和绿色按钮对应，调整框为空时不替换。

UX:
- Flow：选中文字 → Ctrl+C+C / Ctrl+A+A → 结果 → Return 替换；调整框输入 → Return 调整 → 结果。
- Surface：现有浮窗内的一张结果岛；加载、错误与结果同位置。
- States：空选区显示重选提示；请求失败可重试；只读结果可复制，替换禁用；失效选区显示错误。
- Words：快速翻译、快速改写、译文、修改结果、替换、继续调整译文、继续调整措辞。
- Access：Return 动作随输入焦点改变，IME 使用原生处理，按钮有文字或标签及悬停提示。

## STORY-072：左右对照编辑

手动输入和处理文字时，原文和结果同时可见，便于比较。

验收：REQ-072、075；两侧等宽等高、标题/正文/底栏对齐，共用 14 pt 字体与 22 pt 行高；快速入口不另开窗口。

UX:
- Flow：打开翻译 / 打开改写 → 左侧输入 → Return 提交 → 右侧阅读 → 复制或替换。
- Surface：同一浮窗的左右两张岛，各自滚动。
- States：右侧空状态、处理中、结果、错误；保留复制、修改解释与调整输入。
- Words：翻译、改写、译文、修改结果、复制结果、替换。
- Access：Shift+Return 换行；原生红绿灯、键盘焦点及输入法；调整操作和快速模式复用组件。
